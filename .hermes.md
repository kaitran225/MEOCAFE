# HienXanh POS — Hermes rules

This file takes precedence and suppresses auto-loading of AGENTS.md
(first-match-wins), so: **read AGENTS.md first** — it owns the build
commands, project layout, conventions, and pitfalls. This file only adds
Hermes-specific behavior.

## Verification

- The only gate is `dotnet build HienXanh.sln` (no test project exists).
  "Done" = build passes + the change exercised another way (grep gates,
  scripts, manual check the user ran).
- Never launch the GUI (`dotnet run`) to verify unless the user asks —
  it is a blocking WinExe that opens a window on their machine.
- Useful grep gates after UI work: zero hex literals outside
  `Styles/Theme.axaml`, zero `Button.Styles` in views, zero inline
  money/date `StringFormat` targets beyond the known debt list.

## Visual references

- The vision backend on this provider may reject image input. When the user
  sends a screenshot to match: extract the palette with PIL (dominant colors,
  spatial grid, corner probes) and verify WCAG contrast in a script BEFORE
  editing `Theme.axaml`. See the `hienxanh-pos` skill for the full procedure.

## Always

- UI copy is Vietnamese, sentence case; money `{0:N0} ₫`, dates `dd/MM/yyyy`.
- Both theme variants (Dark and Light) change together in the same edit.
- Do not commit or push unless asked.
